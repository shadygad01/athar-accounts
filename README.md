# نظام الحسابات — مجموعة شركات آثار للسياحة

تطبيق ويب عربي يضم خدمتي حسابات: "حسابات خاصة" لمتابعة عملاء يودعون مبالغ على دفعات
وتُحسب لهم فوائد شهرية، و"حسابات الموردين" لمتابعة موردين يورّدون مبالغ بعملة أجنبية
تُسدَّد لهم بالجنيه المصري على دفعات. لكل خدمة كشف حساب احترافي بصيغة bank statement
قابل للطباعة أو الحفظ كـ PDF.

الصفحة الرئيسية (`/`) شاشة لاختيار الخدمة، وكل خدمة لها مسارها الخاص:

- `/clients` — حسابات خاصة
- `/suppliers` — حسابات الموردين

## حسابات خاصة (`/clients`)

- تسجيل عملاء وربط كل عميل بدفعة أو أكثر (شرائح)، كل شريحة تُحسب فائدتها من تاريخها الخاص.
- جدول معدلات عائد سنوي (بحسب السنة الميلادية) يُطبَّق تلقائيًا على حساب الفائدة الشهرية.
- فائدة بسيطة غير مركّبة: تتراكم في رصيد "فوائد مستحقة" منفصل عن الأصل.
- تسجيل مسحوبات من الأصل أو من الفوائد المستحقة، مع حساب تناسبي (Pro-rata) لفائدة الشهر
  عند السحب من الأصل في منتصفه.
- كشف حساب زمني كامل لكل عميل حتى أي تاريخ يتم اختياره، يعرض كل حركة (إيداع / فائدة شهر /
  سحب) والرصيد بعد كل حركة، وإجمالي المستحق = أصل المبلغ + الفوائد.

## حسابات الموردين (`/suppliers`)

- تسجيل موردين، كل مورد بعملة ثابتة (درهم إماراتي أو ريال سعودي) ورصيد سابق افتتاحي بالجنيه المصري.
- تسجيل توريدات (وارد) بعملة المورد، مع معامل صرف يُتفق عليه لكل معاملة على حدة — قيمتها
  بالجنيه المصري = المبلغ × المعامل، وتُضاف إلى الرصيد المستحق للمورد.
- تسجيل سدادات (مصروف) بالجنيه المصري مباشرة على دفعات، تُخصم من الرصيد المستحق.
- كشف حساب زمني كامل لكل مورد حتى أي تاريخ يتم اختياره، بنفس شكل كشف الحساب البنكي: م، تاريخ،
  بيان، مصروف، وارد (معدل / مبلغ)، ورصيد بعد كل حركة.

## مشترك بين الخدمتين

- طباعة أو حفظ أي كشف حساب كـ PDF بتنسيق احترافي.
- حفظ محلي داخل المتصفح لكل خدمة على حدة.

## التشغيل محليًا

```bash
npm install
npm run dev
```

> لا تُرسل بيانات العملاء أو الموردين إلى أي خادم خارجي. يُنصح بأخذ نسخ احتياطية دورية من
> بيانات المتصفح.
